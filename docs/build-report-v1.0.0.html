🖥 守护进程 lingos-assistantd（daemon/）

  • FastAPI 本地 API（仅 127.0.0.1:47831，token 鉴权，令牌桶限流，1MB 上限）
  • SQLite WAL + 内置迁移器 + 损坏自动隔离重建（.corrupt 备份）
  • LLM 客户端：openai SDK 流式、指数退避重试、熔断器（5 次失败 OPEN 60s，半开单探测）
  • 上下文裁剪：token 估算、超窗摘要压缩、失败截断兜底
  • 工具系统：shell / file_read / file_write / file_delete / system_info / gsettings_set
  • ChatService：工具调用循环、逐条确认流、allow_batch 目录前缀、参数自纠 ≤2 轮、取消 kill 进程组、重启后 pending 一律 failed

🛡 安全执行器（executor/）

  • guard：正则 + shlex 双重黑名单（提权/毁灭命令/管道注入/保护目录写），命中即拒绝、不可确认
  • 敏感路径黑名单（~/.ssh、~/.gnupg、~/.config、/etc、/boot、*.token、*.pem、id_rsa*）
  • gsettings 白名单 14 键；风险三级标签（低/中/高）
  • systemd-run 资源隔离（MemoryMax=1G / CPUQuota=100%），超时 kill 整组
  • FreeDesktop 回收站（永不真删）+ 写前自动备份（保留 50 份）
  • 审计日志全留痕（删会话不删审计）

🪟 桌面 UI + GNOME 扩展

  • GTK4 + libadwaita：主窗口（历史侧栏/聊天/设置/审计）、快捷面板（Super+L，600×720）
  • 确认对话框：命令原文/diff 预览 + 风险标签 + 批量允许（同工具同目录）
  • OOBE 三步引导、空状态快捷卡片、无 Key 横幅、草稿 5s 暂存
  • GNOME 46 ESM 扩展：全局快捷键、托盘四态（就绪/降级/无 Key/无服务）、工具能力开关

📦 打包 / ISO / 仓库 / CI

  • 3 个 deb：lingos-assistant（venv 离线可装）、gnome-shell-extension-lingos、lingos-default-settings（壁纸/dconf/OOBE/ Plymouth）
  • live-build ISO：去 snap、Firefox/LibreOffice deb 版、中文 locale、GRUB"LingOS"品牌
  • apt 仓库：apt-ftparchive + GPG 签名，GitHub Pages 托管

  • release.yml：tag 触发 → 签名 → 仓库索引 → ISO → QEMU UEFI 冒烟 → Release
